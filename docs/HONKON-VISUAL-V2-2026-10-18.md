# Hon-Kon: оформление по первоисточнику, версия 2

18 октября 2026

План: вместо прежней витрины с боковыми карточками — редакционная страница студии, по композиции hon-kon.ru/about: крупный лёгкий заголовок, прозрачный леденец справа, узкая навигация с подчёркиванием, широкие секции и разделители. Команда: роль в левой колонке, фотографии справа, подписи на фото и публичные социальные ссылки. На телефоне роль располагается над сеткой из двух карточек.

Цвета: наследуемые AnimeShadow background #0a0b10, card #12141c, foreground #e9eaf0, muted #969db0, primary #ff4d6d. Никакой отдельной фиолетовой темы. Шрифты уже установленные Onest и Unbounded; крупные заголовки с более лёгким начертанием, интерфейс остаётся привычным. Леденец из официальной страницы перегенерируется в коралловой гамме через встроенный imagegen, фон прозрачный.

Проверка направления: убраны одинаковые информационные плитки, гигантские счётчики и имитация статистики. Фирменный характер передают материал леденца, типографика, портреты, авторские подписи команды и сетка по ролям. Анимации отвечают на hover/focus, на телефоне и при reduced motion лишние эффекты отключаются.

Данные: https://www.hon-kon.ru/about — 23 карточки по ролям, 21 фотография (Veta встречается в трёх разделах). Публичные ссылки нормализованы только для явной ошибки /t.me/username. Изображения не генерируются и не подменяются лицами других людей.

Просмотр: карточка открывает реальный плеер выбранного аниме. По новому запросу используется собственная озвучка Hon-Kon Studio из Kodik (translation ID 4167). Видео не создаёт фоновые запросы до открытия; закрытие уничтожает плеер. Если у того же аниме поток отсутствует, другой тайтл не подставляется.

## Итог реализации

- Сохранены 21 оригинальное изображение профилей и 23 карточки участников по четырём ролям. В карточках — публичные подписи авторов; ссылки ведут на настоящие каналы участников. Нажатие на фотографию открывает полноразмерный просмотр и ссылки. Отсутствующие ссылки не выдумывались.
- Фотографии: локальные WebP-превью, полные версии загружаются только при открытии; Veta использует один и тот же файл в трёх разделах. Все 42 файла (превью + полные версии) занимают около 2 МБ.
- Леденец: `apps/web/public/studios/hon-kon/lollipop-coral-v2.webp`, 1000×1000, прозрачность сохранена, около 131 КБ. PNG сохранён рядом для дальнейшей работы.
- Наведение и клавиатурный фокус показывают название и действие на постере; портреты мягко меняют масштаб и насыщенность. На сенсорных экранах и при reduced motion эффекты отключены.
- Карточка аниме открывает реальный плеер того же тайтла. Контекстный просмотр ограничен источниками Hon-Kon; другая студия при сбое автоматически не подставляется. Начальная серия берётся из доступных эпизодов студии, а ссылка на полную страницу сохраняет выбор Hon-Kon. Кода iframe в этом предпросмотре нет.
- Предпросмотр не включает автоматическую запись прогресса и просмотренных часов, не берёт позицию из сохранённой истории. На обычных страницах прежнее поведение сохраняется.
- При открытии страницы видеоэлементов нет. После закрытия предпросмотра плеер удаляется и декодер освобождается. Проверено воспроизведение «Ледяной стены 2» в озвучке Hon-Kon: HLS HTTP 200, три варианта качества, readyState 4, 640×360, воспроизведение прошло 26 секунд без ошибки декодера.
- Проверены 320/375/1280/1440 пикселей: каталог, команда, полноразмерное фото и видеоплеер без горизонтального переполнения. На 320 пикселях команда расположена в две колонки; у руководителя подпись рядом с фотографией.
- TypeScript web/API и production-сборка прошли. Все 25 регрессионных проверок плеера, сопоставления эпизодов и API студии прошли. ESLint без ошибок; в старом watch-section остаётся предупреждение Fast Refresh об экспорте вспомогательной функции.
- Изменения локальные; деплой не выполнялся.
