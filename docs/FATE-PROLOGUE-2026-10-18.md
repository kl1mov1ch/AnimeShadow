# Fate UBW: отдельно опубликованный пролог

18 октября 2026

## Причина

MAL/Shikimori 27821 имеет отдельную карточку пролога. Kodik возвращал пустой результат по этому ID, а поиск по названию находил сериал 22297, который корректно отклонялся как другой тайтл. В живом ответе сериала пролог присутствует в `seasons[0].episodes[1]` у трёх озвучек. Основной сезон хранится отдельно в `seasons[1]`.

Официальная нумерация пролога — #00: https://www.fate-sn.com/ubw/sp/story/.

## Исправление

- Добавлен отдельный реестр проверенных различий между идентификатором каталога и расположением эпизода у провайдера: `packages/kodik/src/episode-identities.ts`.
- Сначала выполняется обычный запрос по точному ID. Только при его отсутствии и наличии проверенной записи берётся указанный эпизод родительского релиза. Подобие названия не является основанием заимствовать чужой тайтл.
- Для 27821 доступен только специальный эпизод, отображаемый как единственная серия. URL всего сериала не используется. Общий Kinopoisk ID не переносится, иначе Alloha мог бы открыть основной сезон вместо пролога.
- Сезон 0 исключён из обычной карты серий; повторяющиеся ключи больше не затирают друг друга. Для затронутых карточек предусмотрено однократное обновление старого кеша, включая отрицательный результат.
- AniLibria не вернула отдельного релиза по точному ID; AnimeVost нашёл основные сезоны, но не отдельный пролог. Эти ответы не подменяются похожим произведением. Общий Kinopoisk ID сериала не используется для поиска пролога в Alloha: он не подтверждает отдельный спецвыпуск.

## Проверка

- API 27821 возвращает три источника своего HLS-плеера: AniLibria.TV, AniDUB, KANSAI Studio, каждый с одной серией.
- HLS master AniLibria.TV ответил HTTP 200, EXTM3U, реальные варианты 360/480/720p.
- Добавлены регрессионные тесты: точный ID приоритетен, отсутствующий пролог не подменяется сериалом, Sunny Day не получает чужой эпизод, все озвучки сохраняются.
- Полный набор: 71 тест, без ошибок.

- В браузере подтверждены декодирование 640×360, readyState 4 и продвижение времени от 1,35 до 11,08 секунды. Проверочное воспроизведение остановлено. Скриншот: qa-fate-prologue-2026-10-18.jpg.
