# Hon-Kon Studio: интеграция и проверка

18 октября 2026. Изменения находятся в локальном проекте; публикация на production не выполнялась.

## Страница студии

- Сохранён глобальный хэдер AnimeShadow, отдельная навигация студии убрана. Hon-Kon стоит первым в совместной подписи, рядом используются настоящие логотипы обеих сторон.
- Коралловая гамма, шрифты и кнопки сайта; оригинальные фотографии команды и постеры студии подготовлены в локальном WebP. Полноразмерные портреты открываются отдельно.
- Более компактные карточки релизов, три карточки дабберов в строке на телефоне. Проверена ширина 375 px: горизонтального переполнения нет, при открытии страницы видеоэлементов нет.
- Блок «Аниме объединяет» перенесён вниз. Декоративная надпись HON-KON теперь обычный приглушённый заполненный текст без обводки.
- Панель управления релизами выводится только при подтверждённой авторизации с ролью ADMIN. Команды синхронизации и проверки дополнительно защищены authenticate + requireAdmin на сервере.
- Подборка студии закреплена в подборках; добавлен фильтр dubbingStudio в каталоге и отдельная вкладка календаря. Календарь обозначает оригинальные даты трансляций, не выдавая их за дату выхода озвучки.

## Источники и серии

- Полная постраничная выборка Kodik по translation ID 4167, включая записи без Shikimori ID. Одновременные запросы объединяются, успешный результат кэшируется, при сбое сохраняется предыдущая выдача.
- На момент проверки: 13 записей студии, из них 12 связаны с каталогом. Новые серии подтянулись, включая вторую серию Нии Листон и третью FX Куруми.
- «Дьявол может плакать (2025)», serial-74964, не имеет идентификатора каталога у провайдера. Добавлен безопасный поиск по точному названию и году; неоднозначные совпадения отвергаются. Несопоставленные релизы доступны отдельно на странице студии через собственный плеер: у этого сериала показаны все 8 настоящих серий.
- Проверены все 74 HLS-источника: 74 успешных ответа, 0 ошибок. Это проверка получения доступного потока, не полный просмотр каждого эпизода.
- В браузере первая и восьмая серии «Дьявол может плакать (2025)» достигли readyState 4, 1280×720, без ошибки видео. Восьмая серия воспроизводилась более 15 секунд.
- Устранены повторения одного URL под разными номерами серий; объединяются дополнительные эпизоды одной подтверждённой записи. Частичное совпадение названия не позволяет брать другой сезон.
- Для холодного собственного Kodik HLS допускается до 20 секунд на начальную подготовку. После появления метаданных сохраняется трёхсекундная проверка зависания, с учётом паузы, скрытой вкладки и отсутствия сети.

## Трейлеры

- RSS официального YouTube-канала UCKPtzE-QBrgzmIhR9eCiY3w импортировал 6 реальных роликов. Они не получают выдуманный anime ID. Явно обозначенные трейлеры Kodik поддерживаются отдельно, но на момент проверки таких записей студии нет.
- Официальный YouTube IFrame API используется только при открытии ролика. Кнопки сайта: воспроизведение/пауза, перемотка, звук, громкость, поддерживаемые скорости, полный экран при наличии поддержки браузера.
- Свои кнопки расположены под iframe. Само видео остаётся официальным YouTube embed; его служебные элементы, логотип и ограничения не обходятся. При отказе API предусмотрен стандартный embed и ссылка на канал.
- Проверены воспроизведение, перемотка до конца, выключение звука и 1,5×. Мобильный iframe: 325,6×200 px при ширине страницы 375 px; кнопки не выходят за рамки. Превью выводятся без обрезки.
- После закрытия диалога плеер уничтожается, таймеры освобождаются.

## Комнаты

- Перед созданием комнаты: имя, вместимость, приватность, управление всеми, ожидание медленного участника, автопродолжение.
- Из студии создаётся комната только с озвучкой Hon-Kon. Ограничение проверяется сервером, сохраняется при восстановлении комнаты и переключении серии/тайтла. Недоступная серия не заменяется другой озвучкой.
- В браузере создана и проверена закрытая комната на 4 человека: 1/4 участника, источник Hon-Kon, поток декодировался в 1280×720. После проверки выполнен выход через интерфейс; пустая комната использует штатное время ожидания.

## Обновление карточек релизов

Карточки главной студии и страницы релизов приведены к пропорциям AnimeShadow: постер 2:3, спокойная рамка, название до двух строк и короткая строка года/серий. Убраны увеличение картинки, выезжающий текст и повтор названия на постере; при наведении появляется только кнопка запуска. Внизу постера остаётся небольшая подпись с настоящим знаком Hon-Kon. На телефоне кнопка запуска доступна без наведения.

Оба статуса используют один нейтральный тёмный фон. У «Выходит» постоянно пульсирует маленький коралловый LIVE-индикатор (только transform/opacity, без таймеров JavaScript). У «Завершён» — спокойная галочка. При prefers-reduced-motion анимация отключается.

Проверены 320/375/640/768/896/1280 px: от двух до шести колонок, горизонтального переполнения нет, все плашки остаются внутри постеров. Наведение на «Ледяную стену 2» не меняет геометрию карточки, кнопка запуска не выходит за рамки. Диалог просмотра открывается. ESLint, TypeScript web и production-сборка прошли. Новые функциональные тесты для этого изменения оформления не добавлялись.

Снимки: `qa-honkon-cards-hover-2026-10-18.jpg`, `qa-honkon-cards-mobile-2026-10-18.jpg`. Изменения локальные, без деплоя.

## Цельная шапка и зацикленная анимация

Знак Hon-Kon и название объединены в один блок. Убраны повторная верхняя подпись, декоративная вертикальная надпись и нижние факты в шапке. Леденец больше не смещается за край отрицательными отступами: на широком экране он занимает собственную колонку, на телефоне расположен между названием и описанием. Мягкое движение леденца зациклено на 8 секунд; reduced motion по-прежнему отключает анимации.

Проверены шапки при 896 и 375 px. На телефоне вся картинка с палочкой находится внутри hero, горизонтального переполнения нет. Снимки: `qa-honkon-hero-complete-desktop-2026-10-18.jpg`, `qa-honkon-hero-complete-mobile-2026-10-18.jpg`. TypeScript web, ESLint и production-сборка прошли.

Отдельная анимация переделана без слогана и подписи партнёрства: только лисий знак и Hon-Kon Studio в одной композиции. Кадр не гаснет; мягкое движение и свечение возвращаются к исходному состоянию за 8 секунд. Готовый GIF: `docs/prototypes/hon-kon-logo-loop.gif` (960×540, 120 кадров, 8000 мс, loop=0, около 2,7 МБ). Среднее различие последнего и первого кадров не превышает различия соседних кадров. Интерактивный прототип и экспортёр видео: `hon-kon-logo-loop.html`; прежний HTML обновлён тем же содержимым. На сайт отдельная анимация логотипа не вставлялась.

В браузере сформировался MP4 1280×720, длительность 7,99 секунды, loop=true. Его скачивание зависло и не завершилось подтверждённым файлом, поэтому для передачи используется проверенный GIF. После этого управление браузером стало недоступно; временные вкладки и сброс тестового размера браузера завершить не удалось.

## Уточнения оформления и воспроизведения

- HON-KON внизу страницы теперь набран точным официальным шрифтом Bebas Neue, без обводки и SVG-текста. Шрифт размещён локально вместе с OFL-лицензией. Размер зависит от ширины блока, а не всего экрана.
- Леденец заменён на изображение с целой закрытой округлой палочкой; кнопки шапки используют компоненты AnimeShadow. На 320/375/896 px горизонтального переполнения нет.
- Иконка Hon-Kon в общем хэдере — 18 px внутри обычной кнопки 36 px, без расширения и подписи на больших экранах. Знак в шапке студии плавно прорисовывается красным за цикл 7 секунд. Один наблюдатель останавливает его вне экрана; reduced motion оставляет статичный знак. Видеофайл или GIF для этой анимации не загружается.
- Секции студии получают однократное появление без обработчиков скролла и тяжёлых фильтров. Содержимое остаётся доступным при отключении анимаций.
- Карточки YouTube увеличены: три колонки на широком экране, две на среднем, одна на телефоне. Используются большие официальные превью с переходом к резервному изображению при ошибке. По последнему пожеланию пользователя видео открывается в обычном YouTube iframe с родными кнопками; прежний компонент собственных YouTube-кнопок удалён.
- Исправлен контейнер отдельного видеоплеера «Других релизов»: собственный поток находится в блоке 16:9, а не перекрывает весь диалог. Проверен реально декодированный поток 1280×720 на телефоне.
- Карточка серии закрашивается по всей ширине мягким розовым пропорционально сохранённой позиции и фактической длительности. Аккаунт видит время остановки; гость не получает персональные позиции из кэша. Прогресс сохраняет часы видео, включая перемотку и паузы, с отправкой при закрытии/скрытии страницы; ключи кэша разделены по аккаунтам. Просмотр со страницы студии также сохраняет прогресс.
- Кодик при преобразовании в HLS сохраняет кадры серий в episodeMeta. Запросы незавершённого перевода метаданных больше не кэшируются браузером на десять минут. Убраны названия-заглушки вида Episode N, мешавшие загрузке настоящего названия. Когда провайдер не публикует кадр, показывается честно подписанный постер аниме; отсутствующие сведения не выдумываются.

### «Свадьба светлячков»

У тайтла 63293 действительно есть Hon-Kon (Kodik 4167), серия 1. Во время поиска других озвучек API уже мог сообщить available=true, пока Kodik ещё разрешался; фильтр студии оставался пустым и преждевременно показывал отсутствие источника. Теперь при sourcesPending ожидаются источники именно выбранной студии. Список и автопереход ограничены опубликованными сериями Hon-Kon, а не количеством серий других озвучек.

Проверено локально: HLS endpoint вернул HTTP 200 и настоящий master с 360/480/720; браузер загрузил 1280×720, readyState=4 и воспроизвёл серию одним нажатием. Позиция продвинулась до 14 секунд без ошибки. Чужая озвучка при этой проверке не использовалась.

Проверки: 40 функциональных тестов, TypeScript API/web, ESLint без ошибок (остаётся существующее предупреждение Fast Refresh у watch-section), production-сборка.
