# Мобильный интерфейс и настраиваемое меню

Изменения сделаны локально. На animeshadow.online не опубликованы.

## Нижняя навигация

- Компактная плавающая панель высотой 56 px. На экране 320 px панель с выбранным каталогом занимает примерно 275 px; горизонтального переполнения нет.
- Поиск — обычная третья кнопка, без постоянной розовой заливки. У выбранного раздела название раскрывается справа от иконки. Переходы сделаны на CSS, без покадрового JavaScript; учитывается reduced motion.
- После входа доступны четыре сменяемых ярлыка. Настройки открываются через «Нижнее меню» в меню аккаунта или «Настроить нижнее меню» в бургере: `/profile?studio=navigation`.
- Настройки содержат интерактивный предпросмотр. В нём можно переключать кнопки, не покидая форму. Выбор существующего ярлыка меняет позиции местами, дубликаты запрещены.
- Уведомления из нижнего меню открывают настоящую панель новых доступных серий. Сохранение доступно без PRO.
- Настройки хранятся в отдельной таблице `MobileNavigationPreference`, загружаются небольшим запросом, кэшируются отдельно для каждого аккаунта. Сервер определяет владельца по сессии; переданный в теле чужой userId не используется.

## Поиск по кадру

По последней просьбе пользователя функция полностью скрыта: убраны ссылки в хэдере, футере, палитре поиска, старой шапке главной и настройках навигации. Старые сохранённые ярлыки автоматически заменяются доступными, другие выбранные кнопки сохраняются.

Клиентский `/frame-search` ведёт на главную. Серверная HTML-страница возвращает 301 на `/`; старые API `/search/frame` и `/search/frame/queue` возвращают 404 и не обращаются к провайдеру. Код распознавания сохранён отключённым.

## Хэдер и меню

- Хэдер скрывается при движении вниз и возвращается при движении вверх на телефоне и ПК. Рядом с началом страницы он остаётся видимым.
- Прокрутка обрабатывается через requestAnimationFrame; обновления состояния происходят при смене направления. Изменение scroll lock при открытии Radix не считается пользовательской прокруткой.
- Открытые меню, уведомления и поиск в хэдере удерживают его на месте. Анимация использует правильное CSS-свойство translate.
- Стабильный отступ полосы прокрутки предотвращает сдвиг страницы. В браузере ширина до/после открытия меню совпала: 366 px на телефоне, 1270 px на ПК.
- Анимация бокового меню сокращена до 200 ms, анимированная гостевая картинка заменена логотипом. Полный профиль для бургера запрашивается при открытии.

## Остальные изменения этой работы

- Шапка аниме компактнее, постер остаётся крупным; основные действия помещаются на узких экранах. Убран FAQ. В информации добавлены копируемые названия из существующих данных без нового сетевого запроса.
- Плавающие фильтры каталога стоят выше нижней панели; окно фильтров прокручивается отдельно от кнопки результатов.
- Мобильные формы входа и регистрации сокращены, необязательный код друга свёрнут, декоративная боковая часть остаётся на ПК. Возврат после регистрации учитывает исходную страницу.
- Приглашения к регистрации используют логотип и понятные преимущества. Общий блок показывается снизу и скрывается при активной прокрутке; приглашение у видео находится под плеером и закрывается одним нажатием.
- GIF кодируются в WebP до 384 px с quality 82, без увеличения исходника. Версия кодирования включена в имя файла для обновления старого браузерного кэша. Уменьшена фоновая предзагрузка анимаций.
- TikTok: `https://www.tiktok.com/@anime_shadow_online`. Футер компактнее, документы собраны в раскрываемый блок.

## Проверки и публикация

- 44 автоматических проверки прошли, включая отклонение скрытого ярлыка и восстановление старых настроек.
- `scripts/check-navigation.ts` проверил реальное сохранение, повторный вход, изоляцию двух временных аккаунтов, запрет дубликатов и изменения поиска. Временные записи удаляются в finally.

- Миграция `20261017170000_mobile_navigation` применена локально. Для публикации нужно применить миграции базы и развернуть обе сборки. Существующая таблица пользователей не перестраивается.
