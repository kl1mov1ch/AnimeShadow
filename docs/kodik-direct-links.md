# Kodik → собственный HLS-плеер

Kodik используется для каталога, списка серий и озвучек. Его iframe на
странице просмотра не создаётся. `WatchService.getSources()` преобразует
подходящую озвучку в HLS-источник с отдельным адресом каждой серии:

`GET /api/anime/:id/streams/kodik/:translationId/:episode/master.m3u8`

API находит адрес серии в сохранённых данных Kodik. Передавать произвольные
URL в запросе нельзя. `KodikStreams` использует установленную
[kodikwrapper](https://github.com/thedvxch/kodikwrapper), находит текущий
endpoint провайдера и получает его HLS-варианты. При смене endpoint кэш
сбрасывается. Таймаут всего получения — 18 секунд. Подписанные ссылки
хранятся в памяти две минуты и не попадают в БД или логи.

Master playlist содержит реальные доступные качества. Сегменты загружаются
браузером напрямую с CDN с CORS. API передаёт только плейлист, поэтому
видеотрафик не проходит через сервер сайта. При ошибке интерфейс предлагает
повторить загрузку или выбрать другую озвучку. Внешний плеер не открывается.
Доступность конкретного тайтла зависит от провайдера и региона.

Проверка API, плейлистов и первых сегментов двух серий:

```powershell
node scripts/check-kodik.mjs 20
pnpm test:player
```

Дополнительные HLS-источники: AniLibria и `WATCH_DIRECT_PROVIDERS` из
[player-sources.md](player-sources.md).

В меню «Качество» доступны «1080p · PRO» и «2K (1440p) · PRO». Без подписки
выбор предлагает оформить PRO. Используется реальный поток нужного качества,
если он есть; иначе лучший поток ниже выбранного разрешения масштабируется
через WebGL. В меню при этом указано исходное качество. Повышение резкости
не применяется. «Авто» и обычные качества не включают масштабирование.
При окончании подписки PRO-режим перестаёт применяться. При ошибке GPU или
медленной обработке выбор сбрасывается на «Авто». В нативном Picture-in-Picture
и fullscreen старых iPhone отображается исходное видео без canvas.

После отправки регистрации автоматического перехода к коду нет. Ввод кода
свёрнут прямо под формой. Отдельная страница подтверждения сохранена для
ссылок из писем и повторной отправки. Проверка владения почтой на сервере
сохранена.
