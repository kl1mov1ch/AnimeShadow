## A. Реализовано

### Названия, кадры и качество — дополнительные замечания

Русский заголовок теперь заменяет английское название из источника, а название, написанное по-русски студией, сохраняет приоритет. Перевод сначала обрабатывает названия, затем описания; первый запрос коротко ждёт результат, остальная работа идёт в фоне. Страница получает признак незавершённой обработки и обновляет данные. Повреждённые ответы внешних API не стирают ранее полученные кадры. При неполных данных Kitsu используется Jikan по точному MAL ID. Для фильма единственный эпизод может использовать название и реальный кадр самого фильма.

Для каждой серии сохраняются альтернативные реальные кадры: если один CDN недоступен, список пробует другой. AnimeVost-картинки проходят через существующий кеширующий прокси. Случайные изображения за кадры конкретной серии не выдаются.

Проверены ответы API:

| Аниме | Серии с данными | Русские названия | Кадры |
|---|---:|---:|---:|
| Стальной алхимик: Братство | 64 | 64 | 64 |
| Наруто | 220 | 219 | 220 |
| Атака титанов | 25 | 25 | 25 |
| Человек-бензопила: Резе | 1 | 1 | 1 |

Панель интернета больше не округляет всё к 480/720/1080. Она показывает реальное разрешение потока, использует заявленный в потоке битрейт с запасом, учитывает скорость воспроизведения; при отсутствии битрейта явно показывает оценку. Вывод 1080p/1440p отделён от исходного потока. Масштабирование не объявляется настоящим видео более высокого качества.

В браузере проверены настоящий поток 1080p, вывод 2560×1440 из 1080p и скорость 1,5×: требуемая скорость изменилась с 4,8 до 7,2 Мбит/с. Canvas 2560×1440 действительно присутствовал и отображался.

## B. Требует внешних данных / ограничения

- Полнота названий и кадров зависит от Kitsu, Jikan и озвучек. Перевод машинный и местами требует редакторской правки; одинакового покрытия всех 20 тысяч записей каталога нет. Пустые места не заменяются выдуманными названиями и кадрами.
- 2K при отсутствии такого источника — размер вывода, а не дополнительная детализация исходного видео. Панель говорит об этом явно.
- Для Mulen Pay нужны ключи магазина, согласованные цены в рублях, реквизиты, проверка параметров чека и тестовая транзакция у провайдера. В официальной документации и старом SDK различается состав подписи; это отдельно указано в [инструкции подключения](D:/AnimeShadow/docs/MULENPAY.md). До проверки интеграция отключена.
- Для создания новых коротких клипов нужен доступный `ffmpeg` и рабочий исходный поток. Если их нет, отображаются реальные картинки; имеющиеся клипы сохраняются. Блокировка autoplay браузером также оставляет постер.
- Настройки внутри оригинального Kodik, его региональные ограничения и реклама управляются провайдером. Они не обходились и не удалялись.
- Проверка проводилась локально. Выкладка на боевой домен и внешние кабинеты поисковых систем не выполнялись.
