# Недельный топ и награды PRO

Неделя: понедельник 00:00 МСК — следующий понедельник 00:00 МСК (UTC+3).
Рейтинг `/api/leaderboards/watch?period=week` показывает текущую календарную
неделю. Месячный топ — последние 30 дней, общий — всё время.

Места определяются по времени просмотра, затем по количеству разных тайтлов,
затем по неизменяемому ID аккаунта. Профиль и статистика должны быть публичными,
аккаунт — незаблокированным. В интерфейсе и при выдаче используется один порядок.

Призы: первое место — 7 дней PRO, второе — 5, третье — 3. Если участников меньше,
выдаются только занятые места. Пустая неделя закрывается без призов.

Задача запускается после старта API и раз в минуту. Перед закрытием недели есть
две минуты на последний сигнал плеера. В обычном режиме выдача происходит
в понедельник между 00:02 и 00:03 МСК. При остановке сервера недели начиная
с активации функции обрабатываются после запуска, до восьми за один проход.
Исторические недели до активации не премируются.

`LeaderboardRewardCursor` хранит следующую неделю к обработке;
`WeeklyWatchReward` — место, пользователя, дни, результат и срок PRO после награды.
Курсор, все три продления и квитанции записываются одной транзакцией под
PostgreSQL advisory lock. Параллельные процессы, повторный запуск и сбой посередине
не приводят к повторному начислению. Ошибка откатывает всю выдачу недели.

`addProDays` атомарно прибавляет дни к большей из дат: текущий PRO, пробный PRO,
текущее время. Бессрочный PRO остаётся бессрочным. Строка пользователя блокируется
самим UPDATE, поэтому одновременные продления не перезаписывают друг друга.

Плеер отправляет время раз в минуту и при уходе. Сервер ограничивает его реально
прошедшим временем и исключает пересечения с последней принятой сессией.
Повтор запроса и две параллельные вкладки не удваивают часы. Сигналы одного
эпизода объединяются в текущую сессию, чтобы не создавать строку каждую минуту;
пересечение границы недели разделяется на две сессии. Это защита от повторов
и очевидного завышения, а не доказательство внимательного просмотра человеком.

Миграция: `20261109090000_weekly_watch_rewards`. При обычном deploy выполняется
автоматически до запуска новой версии API.

Проверки: `tests/weekly-watch-rewards.test.ts` и `tests/download-redirects.test.ts`.
Для реальной локальной базы задать `RUN_WEEKLY_DB_TESTS=1` и загрузить `.env`:
тест допускает только localhost/127.0.0.1, создаёт фикстуры в транзакции и откатывает
все изменения, включая выданный PRO. Проверяет 7/5/3, пробный и бессрочный PRO,
приватность, заблокированные аккаунты, одинаковое время, повтор выдачи и повтор сессии.
