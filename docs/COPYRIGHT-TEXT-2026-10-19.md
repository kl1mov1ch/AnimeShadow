# Правообладателям: текст и изменение почты

По присланному владельцем образцу переработан текст на `/copyright` (`/legal?doc=copyright`). Убраны три нумерованных раздела, повторная дата и большая почтовая карточка. Теперь используются обычные абзацы, кликабельный адрес и четыре пункта из образца, с брендом AnimeShadow. Не перенесены неверные для полного видеоплеера утверждения «только фрагменты» и «размещение оригинальных материалов невозможно».

Администратор прямо на странице нажимает «Изменить почту», редактирует адрес и сохраняет или отменяет изменение. Для других посетителей редактор не выводится. Отдельного адреса страницы нет: обновляется существующая общая почта оператора, используемая соглашением, контактами и другими правовыми документами.

Добавлен `PATCH /api/admin/legal/email`: аутентификация и роль ADMIN проверяются сервером, изменяется только поле email, лишние поля отклоняются. Общий редактор реквизитов продолжает работать. Файловые сохранения сериализованы, записываются во временный файл и атомарно заменяют основной; прочие реквизиты сохраняются. GET `/api/legal` и запрос документа не используют HTTP-кэш со старой почтой. До загрузки текущего адреса редактирование недоступно.

Проверено интеграционным тестом: 401 без входа, 403 для обычного пользователя, 422 для неверной почты/лишних полей, сохранение остальных реквизитов, последовательность одновременных запросов и восстановление после перезапуска. В браузере администратор открыл редактор и сохранил тот же текущий адрес; получено подтверждение. Письма не отправлялись. Отправка обращений остаётся обычной mailto-ссылкой и ручной обработкой почты.

Редакция документов/согласий — 2026-10-19. Изменения локальные. Наличие страницы обращений не подтверждает лицензии и не заменяет проверку документов на соответствие применимому праву.
